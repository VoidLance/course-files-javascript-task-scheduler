# JavaScript Task Scheduler

A small, browser-based task list built with plain HTML, CSS, and JavaScript. Add tasks, mark them complete, edit their text, or remove them. Each task displays the time it was added.

> Despite the repository name, this project currently manages a task list; it does not schedule tasks to run at a specified time.

## Features

- Add tasks with the **Add** button or Enter key.
- Mark tasks with a checkbox.
- Edit task text and delete tasks.
- See a timestamp for when each task was created.
- Use the interface without installing dependencies or running a build.

Tasks are held in the page only and are cleared when the page is reloaded.

## Get started

### Requirements

A modern web browser. No package manager, dependencies, or build tools are required.

### Run locally

1. Clone this repository and open its directory.
2. Open `index.html` in your browser.

Alternatively, serve the directory with any static HTTP server and open the local address it provides.

### Use the task list

Enter a task and select **Add** (or press Enter). Use the checkbox to mark it, **Edit** to change its text, and **Delete** to remove it.
